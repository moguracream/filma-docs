# JWT 認証付きサンプル

このフォルダには、Filma API で JWT を取得し、動画一覧・メタデータの取得と動画再生を行うサンプルを収めています。GitHub Pages などの静的ホスティングで実際の API を試せるよう、ブラウザから直接呼び出します。

> **API の動作確認用デモです。本番利用向けの実装ではありません。**
> このサンプルでは `readonly` API キーをブラウザに公開しています。実運用ではキーをサーバーに保管し、サーバー側で JWT を発行してください。会員向けの配信では、JWT 発行前に利用者の認証と視聴権の確認も必要です。このサンプルはそれらを行いません。

- `index.html` : カテゴリ一覧から動画を選択するトップページ
- `video.html` : 選択した動画をプレーヤーで再生するページ
- `jwt_token.js` : API の接続先・キーの設定と JWT の取得
- `script.js` : JWT を使った一覧・メタデータの取得とプレーヤーの初期化

## 使い方

1. `jwt_token.js` の `API_HOST` と `API_KEY` を設定します。一般 API の参照が必要なため、キーの種類は `readonly` を使用します。`embedded` では動作しません。
2. 公開デモ専用の組織・キーと、公開してよい動画・メタデータを使用してください。キーを知る第三者も、その権限で API を利用できます。`fullaccess` は使用しないでください。
3. キーの「アクセス許可ドメイン」に、サンプルを設置するドメインを登録します。ドメイン設定はキーの秘匿や会員認証の代わりにはなりません。
4. 不特定のブラウザから JWT を取得する公開デモでは、デモ用キーの「アクセス許可 IP／CIDR」は空欄にします。設定されている場合は、閲覧者の接続元 IP が許可範囲内である必要があります。
5. ファイルを静的ホスティングに配置し、`index.html` を開きます。

既存キーの `embedded` への一括移行が行われる場合は、移行後もサンプル用キーが `readonly` であることを確認してください。

## API 呼び出しの流れ

1. `POST /filmaapi/token` に `X-Api-Key` ヘッダーでキーを送り、JWT を取得します。URL の `api_key` は使用しません。
2. 取得した JWT を `Authorization: Bearer ...` ヘッダーに付け、動画一覧・カテゴリ・タグ・メタデータを取得します。
3. 再生時は JWT 付きの配信 URL をプレーヤーに渡します。

一覧取得にも使用するため、JWT 発行時に `mediafile_id` は指定しません。動画限定 JWT を発行する `embedded` キーの例とは用途が異なります。

`api_key_ip_access_denied`（403）が返る場合は IP 設定を、`api_key_query_auth_disabled`（403）が返る場合は古いコードが URL にキーを付けていないかを確認してください。
